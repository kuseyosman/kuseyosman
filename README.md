## How I build: vibe coding, done properly

1. **Brief first.** Every project starts with a written brief (e.g. a `CLAUDE.md`) covering goals, rules and a phased plan before any code is written.
2. **Audit before editing.** Phase 0 is always a read-only audit of what already exists.
3. **Small, safe changes.** Additive updates, tested on mobile and desktop, without breaking what already works (URLs, SEO, data).
4. **Honest data.** No invented numbers; anything missing stays blank and gets flagged.
5. **Ship, measure, iterate.** Launch to real users, watch the numbers, improve.
